## Constraints

- Keep the Groq account on Free. API credentials/model names do not prove an account's billing tier; upgrading the account must never be automated.

- Missing key leaves tutoring unavailable; 401/429/5xx/timeouts fail through existing domain errors.
- Keep mission validation, explicit proposal confirmation, evidence validation and idempotent rewards.
- Never include keys, prompts or provider error bodies in logs. No new dependencies, database migrations or API contracts.

## Review focus
